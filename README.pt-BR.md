# Dotfiles v2
Ambiente CachyOS para engenharia de IA. [English](README.md).

Versão inicial para testes, ainda não validada em hardware real. Execute `bash install.sh --dry-run` antes de `bash install.sh`. Os arquivos existentes são preservados em backup. Use `chsh -s /usr/bin/fish` se desejar iniciar a sessão pelo Fish no tty1. Coloque imagens em ~/Pictures/Wallpapers/horizontal e vertical. O tema monocromático é fixo; trocar wallpapers não altera as cores. Super+Enter avança no horizontal, Super+Alt+Enter no vertical; Shift abre o seletor. Docker e Ollama sob demanda. Aplicações externas ainda precisam de validação.
