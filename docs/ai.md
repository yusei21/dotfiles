# AI and ML
Use uv sync inside each project. Install PyTorch using the official selector at https://pytorch.org/get-started/locally/ and its CUDA-specific wheel index; do not mix global Python packages with project environments.
Use nvidia-smi and nvtop for GPU checks. Docker and Ollama should be started manually. Configure NVIDIA Container Toolkit following https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html only if needed.
Agent install references: https://code.claude.com/docs/ ; https://developers.openai.com/codex/ ; https://opencode.ai/docs/ . Verify the Google Antigravity and Kimi official CLI instructions before installation. Never commit tokens.
