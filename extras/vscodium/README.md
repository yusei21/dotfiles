# VSCodium

Close the editor before applying settings. Back up existing User/settings.json, then copy this settings.json into ~/.config/VSCodium/User/. Install extensions from extensions.txt with codium --install-extension ID. Extension downloads are separate from system packages; availability may vary in Open VSX. AI CLIs run in the integrated Fish terminal; no credentials are tracked. Updates are manual; use pacman for the editor and review extension updates in the UI. The monochrome overrides cover common UI and syntax colors, not every extension-specific decoration.
